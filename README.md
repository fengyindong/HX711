STM32F103C8T6 HX711 智能秤
本示例使用STM32F10x标准外设库，实现了一个5公斤量程的称重传感器秤，配备SSD1306 OLED用户界面、四键状态机、校准、去皮、单位切换、过载报警、Flash存储设置以及ESP8266串口数据通信功能。
## 接线
| 模块信号 | STM32F103C8T6 | 说明 ||---|---|---|
| HX711 DOUT | PB12 | 浮空输入，无上拉电阻 |
| HX711 PD_SCK | PB13 | 通道A，增益128（25个时钟周期） |
| OLED SCL | PB6 | 软件I2C，SSD1306地址0x3C |
| OLED SDA | PB7 | 软件I2C |
| 功能键 | PB0 接GND | 内部上拉 |
| 加号键 | PB1 接GND | 内部上拉 |
| 减号键 | PB10 接GND | 内部上拉 |
| 确认键 | PB11 接GND | 内部上拉 |
| 红色报警LED | PB8 | 高电平有效，需串联电阻 |
| 有源蜂鸣器 | PB9 | 高电平有效；若电流较大，建议使用晶体管驱动 |
| 调试串口TX/RX | PA9/PA10 | USART1，波特率9600，8N1 |
| ESP8266 RX/TX | PA2/PA3 | USART2，波特率9600，8N1；TX/RX需交叉连接 |
所有逻辑电路使用3.3V电压，每个模块必须共用GND。请勿从弱的小蓝丸 3.3V稳压器为ESP8266供电；应使用独立的、输出至少500mA的3.3V稳压电源，并共用接地线。5公斤称重传感器通常连接至HX711的E+/E-/A+/A-引脚；请查阅其数据手册，不要仅依赖导线颜色判断。
提供的 0.96英寸四针显示屏为SSD1306型号，分辨率为128×64，1/64占空比的I2C模块。其连接器引脚顺序为“GND、VDD、SCK、SDA”。驱动器使用7位地址0x3C（写入字节0x78），并采用完整的原生列范围0-127；不使用SH1106风格的双列偏移。
如果整个图像被镜像而非偏移，请修改 `inc/oled.h` 中的 `OLED_MIRROR_X` 或 `OLED_MIRROR_Y`。保持
该模块的 `OLED_DISPLAY_START_LINE` 和 `OLED_DISPLAY_OFFSET` 均设为零。  
如需检查对齐情况，请在调用 `OLED_Init()` 后立即临时调用 `OLED_ShowAlignmentTest()`。此时应有一像素边框接触屏幕四条边；验证完成后请移除测试调用，以便应用程序界面能正常刷新。

## 控制
- 功能短按：进入/循环切换“去皮”、“单位”、“限值”、“零点”。  
- 功能长按（1.2秒）：进入校准质量选择。  
- 加/减：选择100/500/1000克校准质量，或调整报警限值。  
- 确认：确认当前显示的操作。
首次启动时，若无有效的Flash校准数据，系统将自动打开校准选择界面。请选择100、500或1000克，按“确定”，清空秤盘后再次按“确定”，然后放置所选质量，并在机械稳定后按“确定”。此时得到的零点值和每克计数将被保存至Flash中。
单位在克（g）、千克（kg）和盎司（oz）之间循环切换。报警判断始终使用克（g）作为单位。报警限值默认为4500 g，可从100 g到5000 g以100 g为步长进行调整。任何测量值超过设定限值或超出-5000 g至+5000 g的物理范围时，PB8指示灯将闪烁并发出PB9蜂鸣声。HX711错误也会触发报警。从早期1 kg固件升级时，旧的Flash记录将被清除，并加载这些新的安全默认设置；请重新校准5 kg传感器。
## ESP8266/MQTT 接口
STM32 每秒通过 USART2 发送一个以换行符分隔的、可读的 JSON 对象。十进制数值在未启用 STM32 `printf` 浮点支持的情况下生成：
{"hx711秤","重量_克":523.4,"523.克","报警限4500.0,"容量_克":5000.0,"稳定":0,"超0,"超量程":0,"状态":"稳定"}```

`state` 字段的取值为 `stable`、`moving`、`over_limit` 或 `over_range` 之一。  
`weight_g` 始终以克为单位报告，而 `display_value` 则遵循秤上选择的 OLED 单位。这样，MQTT 客户端可以在比较报警值时使用克，同时显示秤上所选的克/千克/盎司数值。
ESP8266 Arduino 固件包含在 `esp8266/` 目录下。编辑 `config.h` 文件，安装 ESP8266 Arduino 核心库和 PubSubClient 库，然后上传 `scale_bridge.ino` 程序。该程序会重新连接 Wi-Fi/MQTT，向 `scale/weight` 发布保留的 JSON 数据，向 `scale/status` 发布 `online` 状态，向 `scale/network` 发布网络诊断信息，并订阅 `scale/command` 作为预留的命令通道。最
