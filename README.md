高精度电阻应变式电子秤系统
基于 STM32F103C8T6 的智能称重解决方案,支持多单位转换、校准、无线数据传输及物联网平台集成。
项目概述：
本项目设计并实现了一款高精度、多功能电子秤系统,以 STM32F103C8T6 为主控芯片,采用 1kg 电阻应变式压力传感器配合 HX711 高精度 24 位 A/D 转换芯片,实现分辨率达 0.1g 的精准称重。系统集成了：
多单位实时转换 (g/kg/oz)
一键去皮/归零
多级校准 (10g/50g/100g)
超重声光报警
MQTT 物联网数据上传
操作逻辑基于有限状态机 (FSM) 设计,配备 4 个按键实现全功能交互,所有状态实时反馈于 0.96 英寸 OLED 显示屏。
基础称重功能：
精准称重    利用 HX711 模块读取压力传感器信号,经数字滤波与均值算法处理,称重精度可达 ±0.1g；
单位切换    支持 克 (g)、千克 (kg)、盎司 (oz)四种单位实时切换；
去皮/归零   一键去皮,自动扣除容器重量；归零功能可消除零点漂移；
超重报警    超过量程 (1kg) 时,蜂鸣器发出滴滴声警报,同时 LED 红灯高频闪烁；
校准功能：
长按 功能键 进入校准模式
通过 加/减键 从预设砝码 (10g / 50g / 100g) 中选择校准基准
系统自动计算并存储校准系数,断电保存
人机交互：
0.96 英寸 OLED 显示屏: 实时显示称重值、单位、状态提示 (去皮/校准/报警)
4 按键设计: 基于状态机实现,短按/长按区分不同操作
物联网集成
称重数据与报警信息通过 串口 传输至 ESP8266 模块
ESP8266 连接 Wi-Fi 后,通过 MQTT 协议 上传至云端服务器
支持远程监控与数据记录
硬件架构：
模块	型号/规格	功能
主控芯片	STM32F103C8T6	核心运算与控制,基于标准外设库开发
压力传感器	1kg 电阻应变式传感器	将重量转换为微电压信号
A/D 转换	HX711 模块	24 位高精度 ADC,将模拟信号转为数字量
显示屏	0.96 英寸 OLED (I²C)	显示重量、单位、状态信息
报警模块	蜂鸣器 + LED 指示灯	超重时声光双重报警
无线通信	ESP8266 (UART)	Wi-Fi 连接,通过 MQTT 上传数据
按键输入	4 个独立按键	功能键、加、减、确认键
